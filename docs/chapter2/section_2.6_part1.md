# 2.6 Семантическая обработка, классификация, дедупликация и накопление статистики встречаемости вопросов

Результатом этапа извлечения вопросов (раздел 2.5) является множество Q = {q₁, q₂, ..., q_M}. Однако при обработке множества видеозаписей неизбежно возникает проблема дублирования: одни и те же вопросы формулируются по-разному в разных источниках, а классификация LLM может быть непоследовательной. Данный раздел посвящён методам обеспечения семантической согласованности формируемой базы знаний.

## 2.6.1 Векторное представление вопросов (эмбеддинги)

Основой семантической обработки является отображение текста вопроса в векторное пространство фиксированной размерности посредством модели эмбеддингов [21]:

e: Σ* → ℝ^d

где Σ* — множество всех текстовых строк, d — размерность векторного пространства. В разрабатываемой системе используется мультиязычная модель SentenceTransformer (paraphrase-multilingual-MiniLM-L12-v2) с d = 384, обученная на параллельных корпусах более чем 50 языков [22]. Выбор данной модели обусловлен необходимостью корректного представления русскоязычных вопросов с технической терминологией на английском языке.

Качество эмбеддингов оценивается по способности модели сохранять семантическую близость: для пары вопросов qᵢ, qⱼ с одинаковым смыслом косинусное сходство их векторов должно быть высоким:

cos(e(qᵢ), e(qⱼ)) = (e(qᵢ) · e(qⱼ)) / (‖e(qᵢ)‖ · ‖e(qⱼ)‖) → 1

а для пар с разным смыслом — низким (→ 0). Модель paraphrase-multilingual-MiniLM-L12-v2 демонстрирует усреднённое косинусное сходство 0,82 на русскоязычных парафразах [22], что является достаточным для задачи дедупликации.

## 2.6.2 Семантическая дедупликация на основе FAISS

Задача дедупликации состоит в выявлении пар вопросов (qᵢ, qⱼ), которые являются семантическими дубликатами, несмотря на различие формулировок. Формально:

(qᵢ, qⱼ) ∈ Duplicates ⇔ cos(e(qᵢ), e(qⱼ)) ≥ θ

где θ — порог семантического сходства.

Для эффективного поиска ближайших соседей в векторном пространстве применяется библиотека FAISS (Facebook AI Similarity Search) [23]. FAISS строит индекс над множеством векторов E = {e(q₁), ..., e(q_M)} и обеспечивает поиск k ближайших соседей за время O(M · log M) вместо O(M²) полного перебора.

В системе используется индекс IndexFlatIP (inner product), который при предварительной нормализации векторов эквивалентен косинусному сходству. Алгоритм дедупликации состоит из следующих шагов:

1. Вычисление эмбеддингов для всех вопросов: E = {e(q₁), ..., e(q_M)}.
2. Нормализация векторов: êᵢ = e(qᵢ) / ‖e(qᵢ)‖.
3. Построение FAISS-индекса IndexFlatIP по {ê₁, ..., ê_M}.
4. Для каждого вопроса qᵢ поиск k ближайших соседей: N(qᵢ) = {(qⱼ, cos(êᵢ, êⱼ)) : j ∈ top-k}.
5. Формирование кластеров дубликатов: если cos(êᵢ, êⱼ) ≥ θ, вопросы qᵢ и qⱼ объединяются в один кластер.
6. Для каждого кластера выбирается представитель (каноническая формулировка) — вопрос с максимальной информативностью.

Выбор порога θ является критическим. При слишком низком θ возможны ложные слияния (разные по смыслу вопросы признаются дубликатами), при слишком высоком — дубликаты не обнаруживаются. Экспериментальная оценка (раздел 3.x) показала, что оптимальное значение θ = 0,87 обеспечивает баланс между точностью и полнотой дедупликации.

Для определения канонической формулировки в каждом кластере вводится мера информативности вопроса, основанная на специфичности его лексики [24]:

I(q) = (1/|w(q)|) · Σ_{w ∈ w(q) \ S} idf(w)

где w(q) — множество слов вопроса (после нормализации), S — множество стоп-слов, idf(w) = log(M / df(w)) — обратная документная частота слова w. Вопрос с максимальным I(q) выбирается как канонический, поскольку он содержит наиболее специфичную терминологию.

## 2.6.3 Классификация вопросов по тематическим категориям

Классификация вопросов по тематическим категориям выполняется на двух уровнях: первичная классификация осуществляется LLM на этапе извлечения (раздел 2.5), а уточняющая — на этапе постобработки с использованием эмбеддингов.

**Первичная LLM-классификация.** Языковая модель присваивает каждому извлечённому вопросу тематическую категорию topic ∈ T на основе контекста диалога и содержания вопроса. Данная классификация обладает высокой точностью (F₁ ≈ 0,90), однако может быть непоследовательной при обработке одного и того же вопроса в разных транскрипциях.

**Уточняющая классификация на основе эмбеддингов.** Для обеспечения консистентности применяется метод k-ближайших соседей (k-NN) в пространстве эмбеддингов. Пусть Q_labeled — множество вопросов с подтверждённой классификацией (одобренных администратором). Для нового вопроса q_new его категория определяется как:

topic(q_new) = argmax_{t ∈ T} Σ_{q ∈ N_k(q_new) ∩ Q_labeled^t} cos(e(q_new), e(q))

где Q_labeled^t — множество подтверждённых вопросов категории t, N_k(q_new) — k ближайших соседей q_new среди Q_labeled. Данный подход обеспечивает согласованность классификации с ранее верифицированными данными.
