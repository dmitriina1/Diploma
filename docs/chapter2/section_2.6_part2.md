## 2.6.4 Оценка уровня сложности вопросов

Оценка сложности выполняется на двух уровнях: первичная — LLM, уточняющая — на основе эвристических признаков.

LLM присваивает уровень diff ∈ D = {junior, middle, senior}. Для верификации используется набор признаков:

- Вопросы «Алгоритмы» с базовыми терминами (массив, хеш-таблица) → junior; с продвинутыми (динамическое программирование, графы) → middle; с оптимизационными (NP-полнота, амортизированный анализ) → senior.
- Вопросы «Системное проектирование» → middle/senior по умолчанию.
- Вопросы сравнительного анализа («разница между X и Y») → middle; проектирования с нуля → senior.

Формально: diff_corrected(q) = adjust(diff_LLM(q), features(q)), где features(q) — вектор эвристических признаков, adjust — функция корректировки в виде набора продукционных правил.

## 2.6.5 Накопление статистики встречаемости и оценка вероятности вопросов

Ключевая функция системы — оценка вероятности появления вопроса на реальных собеседованиях. Пусть Q' — дедуплицированное множество вопросов, V = {v₁, ..., v_K} — множество обработанных видео. Для каждого вопроса:

V(q) = {v ∈ V : q извлечён из v}

Итоговая вероятность вычисляется как взвешенная сумма трёх факторов:

P(q) = α₁·f₁(q) + α₂·f₂(q) + α₃·f₃(q)

где:

- f₁(q) = |V(q)| / |V| — частота встречаемости в обработанных видео;
- f₂(q) = |Platforms(q)| / |Platforms_total| — перекрёстная валидация (различные платформы и авторы);
- f₃(q) = max_{v ∈ V(q)} exp(−λ·age(v)) — временная актуальность, где age(v) — время с момента публикации, λ = 0,001 день⁻¹ (период полураспада ≈ 1,9 года).

Весовые коэффициенты: α₁ = 0,5, α₂ = 0,3, α₃ = 0,2. Значение P(q) нормализуется к [0, 100%] и отображается пользователю как «вероятность вопроса».

Рисунок 2.7 — Модель накопления статистики встречаемости

```
┌──────────────────────────────────────────────────────┐
│  Обработанные видео V = {v₁, ..., v_K}              │
│  ┌───────┐ ┌───────┐       ┌───────┐               │
│  │ v₁    │ │ v₂    │  ...  │ v_K   │               │
│  │YouTube│ │Rutube │       │YouTube│               │
│  └───┬───┘ └───┬───┘       └───┬───┘               │
└──────┼──────────┼───────────────┼───────────────────┘
       ▼          ▼               ▼
┌──────────────────────────────────────────────────────┐
│  q*₁ → V = {v₁, v₃, v₇}     P = 47%               │
│  q*₂ → V = {v₂}              P = 8%                │
│  q*₃ → V = {v₁,v₂,v₅,v₈,v₁₂} P = 89%             │

```
