# Дополнения к разделам 2.1–2.4

## Дополнение к 2.1 — Загрузка видеоматериалов и извлечение аудиодорожки

### Добавить после абзаца про унифицированный формат:

Предварительная обработка аудиосигнала включает шумоподавление, нормализацию громкости и переход к спектральному представлению. Шумоподавление основано на методе спектрального вычитания [25]:

Ŝ(ω) = max(|X(ω)|² − α·|N(ω)|², 0)

где X(ω) — спектр зашумлённого сигнала, N(ω) — оценка спектра шума, α ≥ 1 — коэффициент переоценивания шума. Данный метод эффективен для стационарного шума, характерного для записей видеоконференций.

Нормализация громкости к целевому уровню −23 LUFS (EBU R128 [26]) обеспечивает единообразие уровня сигнала между различными источниками видео, что критично для устойчивости последующей ASR-обработки.

[25] Boll S.F. Suppression of acoustic noise in speech using spectral subtraction // IEEE Transactions on Acoustics, Speech, and Signal Processing. — 1979. — Vol. 27, No. 2. — P. 113–120. — DOI: 10.1109/TASSP.1979.1163209

[26] EBU Recommendation R128: Loudness normalisation and permitted maximum level of audio signals // European Broadcasting Union. — 2020. — URL: https://tech.ebu.ch/docs/r/r128.pdf

## Дополнение к 2.2 — Автоматическое распознавание речи (ASR)

### Добавить после описания архитектуры Whisper (перед faster-whisper):

Архитектура Whisper основана на энкодер-декодерной модели Transformer [13]. Энкодер преобразует входную мел-спектрограмму X ∈ ℝ^{1500×d_model} через N_e = 32 слоя с механизмом многоголового внимания (multi-head attention):

Attention(Q, K, V) = softmax(QK^T / √d_k) · V

где Q, K, V — матрицы запросов, ключей и значений, d_k — размерность ключа. Декодер генерирует текст авторегрессионно:

P(w_t | w_{<t}, X) = Decoder(w_{<t}, Encoder(X))

с общим числом параметров ≈ 809M для модели large-v3 и ≈ 809M для large-v3-turbo при сокращённом числе слоёв декодера.

### Добавить про VAD (Voice Activity Detection):

Встроенная система обнаружения голосовой активности (VAD) на основе алгоритма Silero-VAD [27] позволяет автоматически пропускать тихие и немые участки аудио, что сокращает время обработки на 20–40% для типичных записей собеседований, содержащих значительные паузы между репликами.

[27] Silero VAD: pre-trained enterprise-grade Voice Activity Detector // GitHub repository. — 2024. — URL: https://github.com/snakers4/silero-vad

## Дополнение к 2.3 — Извлечение субтитров

### Добавить после описания формата WebVTT:

Формально, файл субтитров в формате WebVTT представляет собой последовательность cue-блоков:

C = {c₁, c₂, ..., c_P}

где каждый cue cᵢ = (tᵢ^start, tᵢ^end, textᵢ), tᵢ^start, tᵢ^end ∈ ℝ⁺ — временные метки в секундах, textᵢ — текстовое содержание. Парсинг WebVTT включает: (1) удаление HTML-тегов и стилевых аннотаций; (2) нормализацию пробельных символов; (3) преобразование временных меток из формата HH:MM:SS.mmm в числовой формат (секунды с дробной частью).

Качество субтитров существенно зависит от их происхождения. Ручные субтитры, созданные автором видео, демонстрируют WER ≈ 3–5% [28], в то время как автоматически сгенерированные субтитры платформ — WER ≈ 10–20%, особенно на технической лексике.

[28] Linder K., Nakhimova D. Closed captions and subtitles in online learning: Accessibility, engagement, and pedagogy // Journal of Educational Technology Systems. — 2022. — Vol. 50, No. 3. — P. 289–305. — DOI: 10.1177/00472395211061190

## Дополнение к 2.4 — Объединение результатов ASR и субтитров

### Добавить формализацию гибридного объединения:

Формально задача объединения состоит в построении итоговой транскрипции T_hybrid из двух источников: T_ASR = {(sᵢ^A, tᵢ^A)} и T_sub = {(sⱼ^S, tⱼ^S)}. Для каждого временного интервала результирующий сегмент определяется по правилу:

T_hybrid = {(s_k^H, t_k^H) : k = 1, ..., K}

где для k-го сегмента:

- Если ∃ sⱼ^S : [tⱼ^S_start, tⱼ^S_end] ∩ [t_k^H_start, t_k^H_end] ≠ ∅, то s_k^H = sⱼ^S (приоритет субтитров по тексту), t_k^H = (tⱼ^S_start, tⱼ^S_end) (приоритет субтитров по таймкодам).
- Иначе s_k^H = sᵢ^A для ближайшего по времени ASR-сегмента, t_k^H = (tᵢ^A_start, tᵢ^A_end).

Данный подход аналогичен методу ROVER (Recognizer Output Voting Error Reduction) [29], применяемому для объединения результатов нескольких ASR-систем, однако в нашем случае источники имеют качественно различную природу (акустический и текстовый), что позволяет использовать дополнительные эвристики для приоритизации.

[29] Fiscus J.G. A post-processing system to yield reduced word error rates: Recognizer output voting error reduction (ROVER) // Proceedings of the 1997 IEEE Workshop on Automatic Speech Recognition and Understanding. — 1997. — P. 347–354. — DOI: 10.1109/ASRU.1997.659110
